# mydepo.md

Сайт-визитка myDEPO — статический, без сервера и базы данных.
Хостинг: **GitHub Pages** (бесплатно). Домен: **mydepo.md**.

Раньше это было приложение на Laravel 7 на платном хостинге smarthost.md.
Laravel использовался только чтобы отрендерить 4 страницы и отправить два
письма с форм — ни базы, ни админки, ни личного кабинета там не было.
Поэтому сайт переведён в чистый HTML.

---

## Структура

```
index.html              →  https://mydepo.md/            (румынская версия)
ru/index.html           →  https://mydepo.md/ru/          (русская версия)
rights/index.html       →  https://mydepo.md/rights/      (правила, RO)
ru/rights/index.html    →  https://mydepo.md/ru/rights/   (правила, RU)
404.html                →  страница «не найдено»

css/     стили          (app.css — основной, responsive.css, swiper.css, fonts.css)
js/      скрипты        (order.js — формы и интерактив, common.func.js, libs/)
img/     картинки
fonts/   шрифты
CNAME    привязка домена — НЕ УДАЛЯТЬ
sitemap.xml, robots.txt
```

## Как править текст

Тексты вбиты прямо в HTML. Русская и румынская версии — **разные файлы**,
поэтому правку текста нужно вносить в оба:

| Что меняете | Румынский | Русский |
|---|---|---|
| Главная страница | `index.html` | `ru/index.html` |
| Правила | `rights/index.html` | `ru/rights/index.html` |

Порядок: открыли файл на GitHub → карандаш (Edit) → поправили → Commit changes.
Через 1–2 минуты изменения на сайте.

Телефон, e-mail и ссылки на соцсети встречаются в каждом файле по нескольку раз
(шапка, футер, блок плавающих иконок) — меняя номер, пройдите поиском по всем
четырём файлам.

## Формы — ТРЕБУЕТСЯ ОДНО ДЕЙСТВИЕ

Форм на сайте две: «Рассчитать стоимость» (только телефон) и форма обратной
связи. Раньше письма отправлял PHP на сервере. Теперь это делает
[Web3Forms](https://web3forms.com) — бесплатно, до 250 заявок в месяц.

**Чтобы формы заработали:**

1. Зайдите на https://web3forms.com, укажите адрес, куда должны приходить
   заявки (сейчас это `Mydepomd@yahoo.com`).
2. Вам на почту придёт **Access Key** — строка вида `a1b2c3d4-...`.
3. Замените во всех четырёх HTML-файлах строку
   `PASTE-YOUR-WEB3FORMS-ACCESS-KEY-HERE` на этот ключ
   (в `index.html` и `ru/index.html` она встречается дважды — по разу на форму).

До замены ключа кнопки отправки будут показывать сообщение об ошибке.

Ключ Web3Forms не секретный — он публичный по устройству сервиса, его видно в
коде страницы. Защита от спама — скрытое поле `botcheck`, оно уже добавлено.

## Домен и DNS

**GitHub Pages не даёт нейм-серверов.** На странице «Modifică nameservere»
в кабинете nic.md ничего от GitHub вписать нельзя — там указывается, кто
обслуживает DNS-зону целиком.

Сейчас зона целиком живёт на нейм-серверах хостинга, от которого мы уходим:

```
NS    ns1.smarthost.md, ns2.smarthost.md
A     @ www mail ftp smtp pop webmail   →  31.131.4.52
MX    mail.mydepo.md (10)
TXT   v=spf1 a mx ip4:31.131.4.52 ~all
```

Когда хостинг отключат, зона умрёт вместе с ним. Поэтому DNS нужно перевезти
на бесплатный DNS-хостинг — например **Cloudflare** (только DNS, CDN включать
не обязательно).

### Порядок (в два шага, чтобы сайт не падал)

**Шаг 1 — перевезти зону, ничего не меняя.**
Создать зону `mydepo.md` в Cloudflare. Cloudflare сам подтянет существующие
записи — проверить, что все из таблицы выше на месте. Затем на странице
nic.md «Modifică nameservere» заменить:

```
Nume NS Primar     →  <первый>.ns.cloudflare.com
Nume NS Secundar   →  <второй>.ns.cloudflare.com
```

(конкретные имена Cloudflare покажет при создании зоны — они у каждого свои)

После этого сайт и почта продолжают работать на старом хостинге, как сейчас.
Убедиться, что всё открывается, и только потом идти дальше.

**Шаг 2 — переключить сайт на GitHub Pages.** Уже в Cloudflare:

```
удалить:  A  @  →  31.131.4.52
создать:  A  @  →  185.199.108.153     (Proxy status: DNS only)
          A  @  →  185.199.109.153     (DNS only)
          A  @  →  185.199.110.153     (DNS only)
          A  @  →  185.199.111.153     (DNS only)
изменить: A  www →  удалить, вместо неё
          CNAME www → sergiu-belinschi.github.io   (DNS only)
```

Важно: **Proxy status = DNS only** (серая тучка, не оранжевая) — иначе GitHub
не сможет выпустить SSL-сертификат.

Записи `mail`, `ftp`, `smtp`, `pop`, `webmail`, `MX` и SPF относятся к почте на
домене. От неё решено отказаться — их можно удалить, когда будете отключать
хостинг. Пока хостинг жив, лучше оставить.

Когда SPF удалите, имеет смысл поставить `TXT @ = v=spf1 -all`, чтобы от вашего
домена нельзя было рассылать письма от чужого имени.

### Как посмотреть новый сайт до переключения

Есть безопасный способ проверить всё на настоящем домене: после шага 1
направить на GitHub только `www`, а корень оставить на старом хостинге.

```
CNAME www → sergiu-belinschi.github.io   (DNS only)
```

и в настройках репозитория Pages указать домен `www.mydepo.md`. Тогда
`www.mydepo.md` покажет новую версию, а `mydepo.md` — старую. Убедились, что
всё в порядке — переносите корень (шаг 2) и возвращаете домен `mydepo.md`.

Локально сайт запускается из папки репозитория одной командой:

```
python -m http.server 8099
```

и открывается на http://127.0.0.1:8099/

## Аналитика

Google Analytics 4, идентификатор `G-PF0R143FH2`. Раньше стоял только на двух
страницах из четырёх — теперь на всех.

## Что было исправлено при переносе

- `/ru/rights` — не грузились 8 иконок связи и два файла стилей (относительные
  пути ломались на вложенном URL);
- отсутствовал `<title>` на обеих страницах правил;
- `og:image` был прописан как `htps://` — превью при отправке ссылки в
  мессенджеры не работало нигде;
- favicon ссылался на `/img/favicon_16x16px.png`, которого не существует (404);
- две ошибки в консоли: `SecurityError` на YouTube-плеере и `TypeError` в
  `order.js`, из-за которого на страницах правил скрипт обрывался;
- переключатель языка никогда не подсвечивал русскую версию;
- `tel:0037368619999` и `wa.me/0037368619999` — префикс `00` вместо `+`;
- в шапке страниц правил стоял другой телефон (`+373 79 017 666`);
- `robots.txt` и `sitemap.xml` отдавали пустой ответ; sitemap был пустой;
- `lang` не соответствовал языку страницы; не было `canonical` и `hreflang`;
- зум на мобильных был заблокирован (`user-scalable=no`);
- вес главной страницы: около 4,8 МБ → 2,3 МБ.

## Возможные следующие шаги

- Перевести `img/icons/*.png` (29 файлов, ~600 КБ) в WebP — экономит ещё
  ~400 КБ, но меняет имена файлов в разметке.
- Загружать `js/libs/swiper.js` (403 КБ) только на мобильных — карусель
  инициализируется лишь при ширине экрана меньше 500 px.
- Самостоятельно хостить jQuery, Materialize и Google Fonts вместо CDN.
- Папка `fonts/` (1,2 МБ) и `css/fonts.css` подключены, но ни одно правило в
  загружаемых стилях эти шрифты не использует. Скорость это не затрагивает
  (браузер не скачивает неиспользуемые `@font-face`), но при уборке можно
  проверить и удалить.
