# mydepo.md

Сайт-визитка myDEPO — статический, без сервера и базы данных.
Хостинг: **Cloudflare Workers** (бесплатно). Домен: **mydepo.md**.

Раньше это было приложение на Laravel 7 на платном хостинге smarthost.md.
Laravel использовался только чтобы отрендерить 4 страницы и отправить два
письма с форм — ни базы, ни админки, ни личного кабинета там не было.
Поэтому сайт переведён в чистый HTML.

---

## Структура

```
index.html              →  https://mydepo.md/            (румынская версия)
ru/index.html           →  https://mydepo.md/ru/          (русская версия)
rights/index.html       →  https://mydepo.md/rights/      (правила, RO)
ru/rights/index.html    →  https://mydepo.md/ru/rights/   (правила, RU)
404.html                →  страница «не найдено»

css/     стили          (app.css — основной, responsive.css, swiper.css, fonts.css)
js/      скрипты        (order.js — формы и интерактив, common.func.js, libs/)
img/     картинки
fonts/   шрифты
sitemap.xml, robots.txt

wrangler.jsonc   конфигурация деплоя — НЕ УДАЛЯТЬ
.assetsignore    что не выкладывать в публичный доступ
```

## Как публикуется

Cloudflare следит за веткой `main`. Любой коммит запускает сборку: Cloudflare
клонирует репозиторий, выполняет `npx wrangler deploy`, тот читает
`wrangler.jsonc` и выкладывает содержимое корня. Шага сборки нет — файлы
публикуются как есть.

Служебные файлы (`README.md`, `wrangler.jsonc`, сам `.assetsignore`) в
публичный доступ не попадают — они перечислены в `.assetsignore`. Без этого они
открывались бы по прямым ссылкам вида `mydepo.md/README.md`.

## Как править текст

Тексты вбиты прямо в HTML. Русская и румынская версии — **разные файлы**,
поэтому правку текста нужно вносить в оба:

| Что меняете | Румынский | Русский |
|---|---|---|
| Главная страница | `index.html` | `ru/index.html` |
| Правила | `rights/index.html` | `ru/rights/index.html` |

Порядок: открыли файл на GitHub → карандаш (Edit) → поправили → Commit changes.
Через 1–2 минуты изменения на сайте.

Телефон, e-mail и ссылки на соцсети встречаются в каждом файле по нескольку раз
(шапка, футер, блок плавающих иконок) — меняя номер, пройдите поиском по всем
четырём файлам.

## Формы

Форм на сайте две, обе на главной (`index.html` и `ru/index.html`):
«Рассчитать стоимость» (только телефон) и форма обратной связи. На страницах
правил форм нет. Раньше письма отправлял PHP на сервере, теперь —
[Web3Forms](https://web3forms.com), бесплатно, до 250 заявок в месяц.

Access Key уже вставлен. Обе формы используют один ключ и различаются полем
`subject`:

| Форма | Тема письма |
|---|---|
| `#send-phone` — шапка, только телефон | `myDepo — cerere telefon / заявка на звонок` |
| `#contacts-form` — блок обратной связи | `myDepo — formular de contact / форма обратной связи` |

Ключ публичный по устройству сервиса — он виден в исходном коде страницы, это
нормально и так и задумано. Защита от спама — скрытое поле `botcheck`.

**Куда приходят заявки** настраивается в панели Web3Forms, а не в коде:
Dashboard → форма → Settings → поле получателя. По умолчанию письма идут на
адрес, которым зарегистрирован аккаунт.

Обязательные поля проверяются в браузере (`js/order.js`, функция `submitForm`) —
теми же правилами, что раньше проверял сервер: у формы обратной связи это
`firstName`, `phone`, `address`, `message`, у короткой — только `phone`.

## Домен и DNS

Домен зарегистрирован на **nic.md**, но DNS-зону обслуживает **Cloudflare** —
нейм-серверы `anna.ns.cloudflare.com` и `fattouche.ns.cloudflare.com`. Прежний
хостинг smarthost.md из схемы сайта выведен полностью.

Текущие записи:

```
CNAME  mydepo.md   →  воркер mydepo        Proxied   (создан Cloudflare)
CNAME  www         →  mydepo.md            Proxied   (нужен для редиректа)
A      mail ftp smtp pop  →  31.131.4.52   DNS only  (почта, старый хостинг)
MX     mail.mydepo.md (10)                           (почта)
TXT    v=spf1 a mx ip4:31.131.4.52 ~all              (почта)
TXT    _dmarc  v=DMARC1; p=none; ...                 (почта)
```

`www.mydepo.md` не отдаёт копию сайта, а делает 301 на корень — как было на
старом хостинге. Настроено через **Rules → Page Rules**:

```
URL pattern      www.mydepo.md/*
Setting          Forwarding URL
Status           301 - Permanent Redirect
Destination      https://mydepo.md/$1
```

`$1` подставляет путь, поэтому `www.mydepo.md/rights/` уходит на
`mydepo.md/rights/`, а не на главную.

Редирект HTTP → HTTPS включён переключателем **SSL/TLS → Edge Certificates →
Always Use HTTPS**. Сертификат выпускает Cloudflare автоматически.

### Почта

Записи `mail`, `ftp`, `smtp`, `pop`, `MX` и оба `TXT` относятся к почте на
домене и по-прежнему указывают на smarthost.md. Пока хостинг оплачен, они
работают.

Когда будете его отключать — удалите их и поставьте вместо SPF
`TXT @ = v=spf1 -all`, чтобы от вашего домена нельзя было рассылать письма от
чужого имени. Заявки с форм это не затронет: они идут через Web3Forms на
`mydepomd@yahoo.com`, а не через почту домена.

### Локальный просмотр

Из папки репозитория:

```
python -m http.server 8099
```

и открыть http://127.0.0.1:8099/

## Что было исправлено при переносе

- `/ru/rights` — не грузились 8 иконок связи и два файла стилей (относительные
  пути ломались на вложенном URL);
- отсутствовал `<title>` на обеих страницах правил;
- `og:image` был прописан как `htps://` — превью при отправке ссылки в
  мессенджеры не работало нигде;
- favicon ссылался на `/img/favicon_16x16px.png`, которого не существует (404);
- две ошибки в консоли: `SecurityError` на YouTube-плеере и `TypeError` в
  `order.js`, из-за которого на страницах правил скрипт обрывался;
- переключатель языка никогда не подсвечивал русскую версию;
- `tel:0037368619999` и `wa.me/0037368619999` — префикс `00` вместо `+`;
- в шапке страниц правил стоял другой телефон (`+373 79 017 666`);
- `robots.txt` и `sitemap.xml` отдавали пустой ответ; sitemap был пустой;
- `lang` не соответствовал языку страницы; не было `canonical` и `hreflang`;
- зум на мобильных был заблокирован (`user-scalable=no`);
- вес главной страницы: около 4,8 МБ → 2,3 МБ.

## Возможные следующие шаги

- Перевести `img/icons/*.png` (29 файлов, ~600 КБ) в WebP — экономит ещё
  ~400 КБ, но меняет имена файлов в разметке.
- Загружать `js/libs/swiper.js` (403 КБ) только на мобильных — карусель
  инициализируется лишь при ширине экрана меньше 500 px.
- Самостоятельно хостить jQuery, Materialize и Google Fonts вместо CDN.
- Папка `fonts/` (1,2 МБ) и `css/fonts.css` подключены, но ни одно правило в
  загружаемых стилях эти шрифты не использует. Скорость это не затрагивает
  (браузер не скачивает неиспользуемые `@font-face`), но при уборке можно
  проверить и удалить.
